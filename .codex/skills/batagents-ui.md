# Batagents UI/UX Skill

You are redesigning Batagents, a Starknet AI-agent marketplace.

Design standard:
- Production-grade AI + Web3 marketplace
- Dark premium SaaS style
- Deep navy/black background
- Starknet purple and cyan accents
- No emoji icons; use lucide-react only
- No generic AI-template look
- No childish gradients
- No fake demo buttons
- Strong spacing, responsive layout, polished micro-interactions

Use:
- shadcn/ui for components
- Tailwind CSS for styling
- lucide-react for icons
- motion for animations
- sonner for toast states
- skeleton loaders, empty states, error states

Core flow:
Connect wallet → Browse agents → View agent → Pay on testnet → Run agent → View output/history/transaction hash

Always improve:
- Homepage hero
- Marketplace cards
- Agent detail page
- Creator dashboard
- Publish agent page
- Payment states
- Mobile responsiveness

Before editing:
- Inspect existing structure
- Do not break wallet, blockchain, Supabase, auth, or payment logic
- Reuse existing design tokens where possible
- Keep code clean and production-ready
