## What is Bat Agents?

Bat Agents is a marketplace where anyone can **build an AI agent, mint it as a tokenized Agentic ID, list it for sale or rent, and get paid automatically every time someone chats with it** — like a digital freelancer that never sleeps.

It's not a Web2 app with a "Connect Wallet" button bolted on. **0G is the backend:**

- 🔗 **0G Chain** — ownership, minting, marketplace listings, payments, rentals, and creator earnings all live as verifiable on-chain state
- 🗄️ **0G Storage** — agent avatars, persona/prompt configs, and encrypted "intelligence" files are stored decentralized, with client-side AES-256 encryption for anything private
- 🧠 **0G Compute** — every chat reply is generated by real decentralized, TEE-verified inference, through 0G's OpenAI-compatible Router — never a wrapped call to a centralized LLM API
- 🪪 **Agentic IDs (ERC-7857)** — agents are tokenized with a standard purpose-built for AI: encrypted, transferable metadata, not a plain NFT pointing at a static JSON file
- 🦊 **Wallet-only auth** — sign in with your wallet, no email, no password

## How It Works

```
Creator                                          Buyer
   │                                                │
   │  1. Connect wallet                             │  6. Connect wallet
   │  2. Build agent (persona, avatar, price)        │  7. Browse marketplace
   │  3. Files → 0G Storage (encrypted)              │  8. Pay / rent on-chain
   │  4. Mint Agentic ID → 0G Chain (ERC-7857)        │  9. Chat unlocks
   │  5. List on Marketplace                          │ 10. Reply ← 0G Compute
   │                                                  │ 11. Usage recorded on-chain
   │  ◄──────────── 12. Earnings accrue automatically ─┘
```

## Why This Is Real 0G, Not "0G-Themed"

We hold ourselves to a simple test — anyone can verify it independently:

1. **Every agent's contract data is on [ChainScan (Galileo)](https://chainscan-galileo.0g.ai)**, verified source.
2. **Every agent's files resolve by Merkle root hash on [StorageScan (Galileo)](https://storagescan-galileo.0g.ai)**.
3. **Every chat reply visibly hits the 0G Compute Router endpoint** — check the in-app "Proof of 0G" panel.
4. **There is no database that decides product truth.** Ownership, listings, access, and earnings are all read directly from 0G Chain; any cache we add is rebuildable from chain + storage, never authoritative.
5. **No Starknet, no Cairo, no centralized LLM fallback, no email/password.**

## Getting Started

> Bat Agents targets **0G Galileo Testnet** (chain ID `16602`) for development and demo.

### Prerequisites

- Node.js 18+
- A wallet (MetaMask) with Galileo testnet 0G tokens — get some from the [0G Faucet](https://faucet.0g.ai) (0.1 0G/day)
- An [0G Compute Router](https://pc.testnet.0g.ai) API key (testnet)

### Add 0G Galileo Testnet to your wallet

| Field | Value |
|---|---|
| Network Name | 0G Galileo Testnet |
| Chain ID | `16602` |
| RPC URL | `https://evmrpc-testnet.0g.ai` |
| Currency Symbol | 0G |
| Block Explorer | `https://chainscan-galileo.0g.ai` |

### Setup

```bash
# Clone
git clone https://github.com/<your-org>/bat-agents.git
cd bat-agents

# Install
pnpm install

# Environment
cp .env.example .env
# Fill in: PRIVATE_KEY (deployer), ZERO_G_COMPUTE_API_KEY, etc. in .env post-deploy

# Compile + deploy contracts (Galileo testnet)
cd contracts
pnpm compile
npx hardhat run scripts/deploy.js --network 0g-testnet

# Run the app
cd ../apps/web
pnpm dev
```

Full setup detail, deployment order, and contract verification steps: [`docs/SMART_CONTRACTS.md`](./docs/SMART_CONTRACTS.md).
